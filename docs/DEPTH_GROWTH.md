# Grow depth with signed residual corrections

Earlier depth comparisons improved enwik8 when they spread a similar
parameter budget across more spiking blocks. The wider 13.03M residual
stream improved PG-19 and lost ground on enwik8. This study compares
depth and residual width around 9.96M parameters. It starts from the
6.51M eight-bit router trained on 72,089,600 enwik8 targets.
[Earlier depth experiment](DEPTH_INHIBITION.md) ·
[Matched width and precision scores](GROWN_RESIDUAL.md)

## Residual pulses carry through the new blocks

The block receives a signed spike packet $x$. Its content, axons and
held-charge trace produce a learned synaptic correction $u$ in charge
units. With output threshold $\theta$, the ordinary block fires at
charge $\theta x+u$. A correction block forwards the incoming pulses
on its residual axon and generates the signed pulse difference

$$
\delta = \operatorname{fire}(\theta x+u) - x.
$$

The receiving populations see $x+\delta$. The integer firing rule
deducts the charge represented by $x$ before counting the correction,
using the same saturation and half-threshold rounding as ordinary
firing. A silent branch forwards exactly $x$. The existing interval
memory and fixed axons still supply the branch's routed spikes.
[Integer spike block](../snnformer/event_lm.py)

Function-preserving depth growth is an established training technique.
Here, all four appended expansion matrices start at zero and the
outgoing synapses start with trainable random weights. The content
neurons receive a next-byte gradient at initialization. The new
steering rectifiers use the right derivative at zero once their
content path becomes active. [Net2Net](https://arxiv.org/abs/1511.05641)

On 4,096 enwik8 validation bytes, every vocabulary count matched the
parent. CPU single-byte, CPU chunks, and Metal counts agreed. Each
appended pool emitted 28,378 inhibitory pulses. The 113,512 additional
pulses were 0.009% of the parent's total. All four added content
matrices received nonzero gradients on 512 enwik8 training targets.
The 11-block decoder uses 29,674 persistent bytes, including charge
and delay rings. Its fixed axon paths cover up to 125 bytes of history.
The schedule's twelfth block would bring the stream state to 34,128 B.
[SNN warm start](../results/event_lm/depth_growth/warm_depth.json)

The width control exactly preserved initial counts and emissions.
The full-attention control grows from four to six blocks and from
1,756 to 1,805 SwiGLU units per layer. It starts the new attention
and SwiGLU output matrices at zero. The new Transformer and its
parent had identical logits on 4,096 validation bytes. All six arms
add 9,830,400 training targets for 81,920,000 cumulative targets. They
use seed 4603, 512-byte windows, batch size eight, and peak learning
rate 0.0002. The SNN keeps 16× firing resolution and targets 310,000
generated pulses per byte. The score uses the full enwik8 test split
and the same 16 complete PG-19 books as the earlier pair.
[Width audit](../results/event_lm/depth_growth/warm_width.json) ·
[Transformer warm start](../results/event_lm/depth_growth/warm_transformer.json)

The seven-block correction arm starts with the same weights and
predictions as the original SNN. Before training, changing the output
rule for all seven blocks reduced generated pulses from 309,180 to
266,690 per byte on 4,096 enwik8 test bytes. The audit counts spikes
generated by firing and memory operations. Forwarded pulses still
drive the downstream synapses. Both training arms use the same
310,000-pulse target, so the correction model can spend the lower
initial output emissions on its other spike populations.
[Same-weights output audit](../results/event_lm/depth_growth/parent_residual_emissions.json)

The seven-block continuation scored 1.84466 bits per byte on enwik8
and 2.80932 on calibrated PG-19 after the additional training. Its
starting checkpoint scored 1.86770 and 2.82082 respectively.

### Seven-block output comparison

| 6.51M comparison | enwik8 bpb | PG-19 calibrated bpb | PG-19 raw bpb | Generated pulses/byte |
|---|---:|---:|---:|---:|
| Ordinary-output SNN | 1.84466 | **2.80932** | **2.91443** | 309,030 |
| Signed corrections at every output | 1.84464 | 2.86794 | 2.99541 | 305,045 |
| 4-block full attention | **1.75773** | 2.93346 | 3.12986 | — |

Training with corrections at every output changed enwik8 loss by
0.00002 bpb and increased calibrated PG-19 loss by 0.05862 bpb
relative to the ordinary-output SNN. On the native audit it generated
1.3% fewer pulses than that independently trained control. At the
correction model's own trained weights, switching to ordinary
re-emission would generate 346,146 pulses per byte at identical
output counts. The signed output saves 11.9% in that fixed-weights
comparison. The released depth checkpoint applies signed output
only to the four appended blocks.

## What the added blocks learned

At the trained 11-block weights, the decoder emitted 309,059
pulses per byte. Switching the same four blocks to ordinary
re-emission at the same weights and identical output counts would
emit 365,063 per byte. Signed correction saves 15.3% of generated
events in that comparison. All four appended steering populations
fired on the test sample. On 65,536 validation targets, silencing
the four new projections increased loss from 1.77115 to 1.77546
bpb. This intervention isolates the trained projections while
retaining the other learned weights.

## Native CPU timing

With two PyTorch CPU threads on the Apple M3 Max, median greedy
decode after a 512-byte enwik8 prompt took 2.05 ms per byte for
the seven-block control and 3.05 ms for the 11-block SNN. Three
repeats each generated 64 bytes after one warmup. Measured stream
state stayed at 19,536 and 29,674 B through both 128- and 512-byte
prompts and generation. The timing records local software
performance with Metal jobs running on the same machine.

## Reproduce

```bash
export PYTORCH_ENABLE_MPS_FALLBACK=0
mkdir -p checkpoints/work
python experiments/audit_residual_growth.py --enwik8 data/enwik8 --device mps \
  --parent checkpoints/finer-router-charge-study/fine_charge_s3307.pt \
  --depth 11 --json checkpoints/work/warm_depth.json
python experiments/audit_growth_gradients.py transformer --enwik8 data/enwik8 --device mps \
  --checkpoint checkpoints/scale-6510k-short-control-study/control_transformer_s3307.pt \
  --seed 4603 --depth 6 --mlp-ratio 10.576171875 --json checkpoints/work/warm_depth_transformer.json
bash experiments/run_v4_continuation.sh depth-growth-control
bash experiments/run_v4_continuation.sh depth-growth-snn
bash experiments/run_v4_continuation.sh depth-growth-wide
bash experiments/run_v4_continuation.sh depth-growth-transformer
bash experiments/run_v4_continuation.sh depth-growth-corrections
bash experiments/run_v4_continuation.sh depth-growth-control-transformer
python experiments/benchmark_decode.py --integer-event --device cpu --threads 2 \
  --checkpoint checkpoints/depth-growth-study/control_s4603.pt checkpoints/depth-growth-study/depth_s4603.pt \
  --contexts 128 512 --steps 64 --warmups 1 --repeats 3 \
  --prompt-file data/enwik8 --prompt-offset 95000000 --json checkpoints/work/decode_control_depth.json
```
